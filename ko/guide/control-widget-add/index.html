제어 위젯 추가 방법

iPhone 제어 센터에 aircal 제어 위젯을 추가하는 방법입니다.

1
먼저 제어 센터를 엽니다. • Face ID가 탑재된 iPhone: 화면 오른쪽 상단 모서리에서 아래로 쓸어내립니다. 계속해서 아래로 쓸어내리면 더 많은 제어 그룹이 표시됩니다. • 홈 버튼이 있는 iPhone: 화면 하단에서 위로 쓸어올립니다. 화면 오른쪽 가장자리의 아이콘을 쓸어넘기면 특정 그룹의 제어 항목으로 빠르게 이동할 수 있습니다. 아이콘을 위로 쓸어올리면 첫 번째 그룹으로 돌아갑니다.
2
제어 센터가 열린 상태에서 화면 왼쪽 상단의 '+' 버튼을 탭합니다.
3
화면 하단에 표시되는 '제어기 추가'를 탭합니다.
4
제어기 목록에서 aircal 제어기를 선택합니다. 검색란에 'aircal'을 입력하면 후보를 좁힐 수 있습니다.
5
선택한 제어기가 제어 센터에 추가됩니다. 드래그하여 원하는 위치로 정렬해 주세요.
