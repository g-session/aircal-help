aircal Pro

aircal Pro란?

aircal 앱 내 광고를 모두 제거하고 기능 제한을 해제하기 위한 인앱 결제를 통한 업그레이드입니다.

aircal Pro에서 다음 기능을 이용할 수 있게 됩니다.

  • 광고 숨김
  • 음성 AI 입력 제한 없음
  • 컬러 테마 모두 사용
  • 위젯 모두 사용
  • 폰트 모두 사용
  • 앱 아이콘 모두 사용
  • 일정 검색
  • 일정 템플릿 사용
  • 주차 번호 표시
  • 길게 눌러 색상 변경

※ 일부 기능은 개발 중이며 순차적으로 제공될 예정입니다.

aircal Pro 비용에 관하여

aircal Pro는 평생 이용권과 구독형으로 제공됩니다.

구매 가격은 아래 순서로 구매 화면에서 확인해 주세요.

aircal Pro 구매 순서

  1. 1.aircal 앱 열기
  2. 2.오른쪽 위의 '설정' 아이콘을 탭
  3. 3.'Pro로 업그레이드'를 탭
  4. 4.aircal Pro 구매

iOS

구매가 반영되지 않아요

  • 통신 환경이 양호한 곳에서 인터넷에 연결되어 있는지 확인해 주세요.
  • 구매 시와 같은 Apple ID로 기기에 로그인되어 있는지 확인해 주세요.
  • 그래도 해결되지 않으면 Apple 지원 창구로 문의해 주세요.
Android

구매가 반영되지 않아요

  • 통신 환경이 양호한 곳에서 인터넷에 연결되어 있는지 확인해 주세요.
  • 구매 시와 같은 Google 계정으로 기기에 로그인되어 있는지 확인해 주세요.
