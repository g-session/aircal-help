aircal Pro

What is aircal Pro?

An in-app purchase upgrade that removes all ads within the aircal app and unlocks feature restrictions.

With aircal Pro, you can use the following features.

  • No ads
  • Unlimited voice AI input
  • All color themes
  • All widget types
  • All font types
  • All app icon types
  • Event search
  • Event templates
  • Week number display
  • Long-press to change color

* Some features are still under development and will be rolled out gradually.

About aircal Pro pricing

aircal Pro is offered as both a one-time purchase and a subscription.

Please check the current price on the purchase screen using the steps below.

How to open the aircal Pro purchase screen

  1. 1.Open the aircal app
  2. 2.Tap the "Settings" icon in the upper right
  3. 3.Tap "Upgrade to Pro"
  4. 4.Purchase aircal Pro

Transferring aircal Pro to another device (restore purchases)

When you change devices, you can restore your purchase status with the following steps.

  1. 1.Open the aircal app
  2. 2.Tap the "Settings" icon in the upper right
  3. 3.Tap "Upgrade to Pro"
  4. 4.Tap "Restore Purchases" at the bottom of the screen
