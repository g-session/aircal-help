Comment ajouter un widget d'écran d'accueil

Qu'est-ce que le widget aircal ?

Une fonction qui permet d'afficher les événements aircal sur l'écran d'accueil ou l'écran de verrouillage (※ iPhone uniquement) de votre smartphone. Vous consultez vos événements et votre calendrier sans ouvrir l'application.

iOS

Comment ajouter un widget d'écran d'accueil

Voici les étapes pour ajouter le widget aircal à l'écran d'accueil de votre iPhone.

1
Maintenez appuyée une zone vide de l'écran d'accueil pour passer en « mode édition » : les icônes se mettent à bouger. Un bouton « Modifier » apparaît en haut à gauche.
2
Touchez le bouton « Modifier » en haut à gauche, puis sélectionnez « Ajouter un widget » dans le menu.
3
Une fois la galerie de widgets ouverte, tapez « aircal » dans la barre de recherche. Touchez aircal lorsqu'il apparaît dans les suggestions.
4
Faites défiler de gauche à droite pour choisir le widget souhaité. La taille (petite, moyenne, grande) et le type peuvent être modifiés plus tard.
5
Touchez « Ajouter le widget » en bas de l'écran.
6
Le widget est ajouté à l'écran d'accueil. Faites-le glisser à l'emplacement souhaité, puis touchez « OK » en haut à droite pour terminer.

Android

Comment ajouter un widget d'écran d'accueil

  1. 1.Maintenez appuyée une zone vide de l'écran d'accueil
  2. 2.Dans le menu, touchez « Widgets »
  3. 3.Trouvez « aircal » dans la liste et touchez-le
  4. 4.Maintenez appuyé le widget souhaité, puis faites-le glisser à l'endroit voulu sur l'écran d'accueil
