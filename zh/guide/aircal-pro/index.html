aircal Pro

什么是aircal Pro？

这是通过App内付费升级，去除aircal应用内所有广告并解锁功能限制的方案。

升级到aircal Pro后可使用以下功能：

  • 不显示广告
  • AI语音输入无限制
  • 全部颜色主题
  • 全部小组件
  • 全部字体
  • 全部App图标
  • 日程搜索
  • 使用日程模板
  • 显示周数
  • 长按修改颜色

※部分功能仍在开发中，将陆续上线。

关于aircal Pro的价格

aircal Pro 提供买断和订阅方式。

购买价格请按以下步骤在购买页面查看。

aircal Pro的购买步骤

  1. 1.打开aircal应用
  2. 2.点击右上角的「设置」图标
  3. 3.点击「升级到 Pro」
  4. 4.购买aircal Pro

想将aircal Pro转移到其他设备（恢复购买）

更换机型等情况下，也可通过以下步骤恢复购买状态。

  1. 1.打开aircal应用
  2. 2.点击右上角的「设置」图标
  3. 3.点击「升级到 Pro」
  4. 4.点击页面底部的「恢复购买」
iOS

购买无法生效

  • 请在网络良好的地方确认已连接到互联网。
  • 请确认设备登录的Apple ID与购买时相同。
  • 若仍无法解决，请联系Apple客服。
Android

购买无法生效

  • 请在网络良好的地方确认已连接到互联网。
  • 请确认设备登录的Google账号与购买时相同。
  • 若仍无法解决，请联系Google Play支持。
